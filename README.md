# Eagles Speed Skate

A static website concept for the inline speed skating branch of Eagles Roller Sports Club.

## Local preview

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Content status

The site intentionally uses labelled photography placeholders until approved photos of club members in Eagles uniform are available. Club schedules, locations, contact details and registration links remain to be confirmed before public promotion.
